### 2.3 Organizer baseline：可借鉴的强监督对照

**[官方材料，Task Overview §3.5，第 4 页]**

- 模型：`meta-llama/Llama-3.1-8B-Instruct`，一个模型同时训练 article 和 subevent 实例。
- 输入：scope、该 scope 对应的文本、目标 actor、54 个 Level-1 价值定义。

### 3.2 “至多两个标签”是需单独控制的限制

按每个 `(guid, subevent_id, actor)` 最多输出两个有向标签计算，DEV 即使选择完全正确，召回理论上限也只有 **95.05%**，至少漏 137 个金标。TRAIN 对应上限是 95.94%。这并不能解释刘目前约 28% 的召回，但说明该限制不是任务规定。

复现刘的历史实验时保留其原始上限。Peiyang 的训练主线不把两个标签上限设成任务要求，所有主实验共享相同输出和阈值协议。若另做上限消融，应单独比较。若刘实际限制的是 value identity 而非 directed tuple，要先看原始 prompt 后重新计算对应上限。

## 4. 重新筛选 idea：优先研究文章—子事件的单向一致性

**建议主线：在同一主体下，联合学习文章级价值和子事件级价值，用“子事件成立则文章成立”的单向约束改善 Task 2。文章级价值可以只在整体叙事中成立，不必强行分配给某个子事件。**

可用研究题目：*Scope-consistent learning for actor-conditioned human value recognition*（面向主体条件价值识别的范围一致性学习）。这是待检验的研究方向，不是已证明的新算法或效果。第一轮以成熟的层级多标签学习方法为起点，研究它在 FEHU 的适用性与失效条件。

### 4.1 Task 2 到底是什么

输入是一篇新闻、**已经给定**的子事件和文章级候选主体。对每个 `(文章, 子事件, 主体)` 输出价值集合。2a 是 20 类粗粒度价值；2b 是 54 类细粒度价值及支持/违背方向。允许多标签和空集。我们不需要重新分割事件，也不评价主体长期的道德品质。

教学示例：同一篇新闻里，工厂排污体现“保护环境”的违背，志愿者清理河流体现支持。Task 1 判断主体在整篇文章中的价值，Task 2 必须把判断落实到具体子事件。示例不是数据集金标。

| [DHRD，2025 预印本](https://arxiv.org/html/2509.21487v1)，§3、§4.3、局限 | 训练专用推理头，预测头只读输入；打乱解释的消融影响性能 | 提供不增加推理生成成本的对照实现；原文主要设置单次运行，不能照搬稳定性结论 |
| [Regularization Through Reasoning，2025 预印本](https://arxiv.org/html/2511.02044v1)，摘要、§5.3 | 特定乱序/随机解释文本也可能有训练收益 | 真解释必须对比同标签打乱解释，排除额外文本或正则化收益 |
| [EIDER，ACL Findings 2022](https://aclanthology.org/2022.findings-acl.23/)，方法与摘要；[DREEAM，EACL 2023](https://aclanthology.org/2023.eacl-main.145/)，摘要 | 证据抽取、证据监督与全文预测结合已有成熟路径 | 可帮助刘的上下文支线，但 FEHU 当前输入没有直接发布句级 gold evidence，第一轮不额外引入银标生成 |
| [QCRD，EMNLP 2025](https://aclanthology.org/2025.emnlp-main.724/)，摘要 | 质量控制和正负解释蒸馏已有研究 | 上一版泛化的“对比学习”定位仍不充分；第一轮不依赖未经验证的语义负例 |
| [IIUoT 官方报告题目](https://research.nii.ac.jp/ntcir/ntcir-19/program.html)，题目级证据 | LoRA 与稀有标签、方向感知过采样 | 在完整研究阶段加入采样对照；未取得全文，不称为 IIUoT 精确复现 |

### 4.3 为什么这条线优先于另外几条

| 候选方向 | 吸引力 | 关键问题 | 当前取舍 |
| --- | --- | --- | --- |
| 主体/事件负例对比，上一版建议 | 直接针对归属错误 | “未标”不等于可靠语义负例，需要审查；普通对比学习不是新贡献 | 保留为后续消融，不作为第一轮主轴 |
| 解释蒸馏 | 训练集已有解释，启动成本低 | EAVIT、DHRD 已覆盖主要构想，收益可能来自额外文本 | 强对照与备选方向 |
| 推理时检索证据、选择上下文 | 接近刘已做的工作，易复用缓存 | 与刘的独立研究问题重叠，还需要句级证据监督 | 由刘继续研究 |
| 单向跨范围约束 | 同时利用现成 Task 1/2 标注，目标关系可以实际核对 | 一致性提高不保证 F1；可能仅等价于难负例加权 | **优先用小规模实验检验** |

这不是“主导人的方法必须比协作者复杂”。你的独立问题是：**在输入相同、监督样本相同的条件下，显式建模价值在文章与子事件之间的关系，能否改善识别？** 刘的问题仍是推理时读哪些上下文，两者可独立成立。

## 5. 支持这个 idea 的实际数据证据

本节来自新运行的[审计脚本](evidence/audit_scope_supervision.py)与[结果 JSON](evidence/scope_supervision_audit.json)，不来自模型推理。连接键是 `guid`，再用 `actor/l1_value/direction` 精确匹配，不能按 JSON 列表位置或主体名称连接。

### 5.1 包含关系成立，但相等关系明显不成立

| 检查 | TRAIN | DEV | 含义 |
| --- | ---: | ---: | --- |
| 子事件有向正标签 | 18,665 | 2,768 | 方向参与匹配 |
| 同主体文章级金标也含该标签 | 18,665 / 18,665 | 2,768 / 2,768 | 当前发布版本中，子事件标签包含于文章标签 |
| 文章级有向标签总数 | 16,905 | 2,390 | 每个文章—主体—价值—方向去重 |
| 未出现在任何子事件中的文章标签 | 4,117，24.35% | 591，24.73% | 必须保留文章独有标签的自由度 |
| 同一子事件—主体—价值同时有两个方向 | 12 | 0 | 不能将支持/违背做成强制二选一 |

第一条关系写作 `Y_subevent ⊆ Y_article`，其中 actor、value、direction 全部保持一致。**不是** `Y_article = union(Y_subevents)`，也不是文章标签必须至少对应一个子事件。4,117 条仅文章标签可能来自整体叙事、事件摘要未覆盖或标注差异，仅凭计数不能进一步判定其语义原因。

NEVU arXiv v1 的诊断子集并非完全相同的包含关系，所以这不是通用伦理规律，更不是任意新闻标注都成立的定理。当前方法针对已核对的 FEHU 发布版本。新数据若出现违反关系的 gold，必须显式报告并重新判断约束适用性，不能悄悄修 gold。

### 5.2 任务难点有一部分是“在哪里成立”

TRAIN 的完整输出空间有 `30,543 × 108 = 3,298,644` 个二元标签位置，仅 18,665 个为正，占 **0.566%**。若**只作 oracle 分析**，限定为同主体文章金标已存在的价值，再检查它在哪些子事件成立，则有 157,716 个位置，正例密度为 **11.83%**。

这说明文章范围的信息有潜力帮助定位，但 **11.83% 使用了 gold article labels，不是可部署模型的能力，也不是预计性能提升**。真正系统必须面对预测错误，不能在 DEV/TEST 用文章金标选候选。

在 12,788 个出现于至少一个子事件的文章—主体—有向价值中，9,098 个只在一个子事件有金标。反过来，同一标签也可以在多个子事件成立，最多观察到 12 个。因此不能用 softmax 强制“每个价值只能归一个事件”，也不能强制“每个主体都有标签”。

### 5.3 解释监督确实可用，但先作为独立对照

18,665 条 TRAIN 子事件正标签全部有非空 `explanation`，词数中位数 27、95 分位数 36。本次只验证字段覆盖与长度，未逐条核实语义。解释来自标注过程，可能重复标签名称、依赖全文，甚至继承标注错误，不等于天然正确的因果推理。

解释只能作为 TRAIN 的监督目标或训练专用信息，不能进入正常 DEV/TEST 输入。主方法第一轮不依赖解释，所以能单独验证范围约束。后续解释对照必须保留相同标签、方向和大致长度后打乱解释，不能把“解释与标签同时打乱”的灾难性结果当成充分证据。

### 5.4 必须修正验证设计：GUID 不重叠仍然会重复正文

采用“合并空白、Unicode casefold，保留标点”的正文标准化后：

- TRAIN 1,228 条记录对应 912 个不同正文；按相同正文或相同标题形成连通组后是 848 组。
- DEV 177 条中，**86 条（48.59%）**与 TRAIN 有相同标准化正文，其中 81 条连原始正文都逐字相同。
- Task-2 TEST 175 条中，74 条与 TRAIN 正文相同。这只使用公开输入，没有读取测试金标。

这些记录的主体、子事件和标签可能不同，不能把“正文重叠”直接说成“答案完全重复”，也不能据此计算成绩虚高多少。但只按 GUID 随机切分不足以证明新新闻泛化。我们不改官方文件和官方分数定义，而是增加独立的来源分组验证，并分层报告官方 DEV。

还发现 TRAIN gold 有 5 条空 `subevent_id`、空标签记录，以及 134 个输入子事件没有可定位的 gold 行。审计保留异常计数，不猜测空 ID 属于哪一事件。训练实例从输入全集建立，没有正标签的实例按官方发布集合语义为空；这不构成人工确认的“事件无价值”标注。

## 6. 一个可以实现的最小方法

### 6.1 模型与数据单元

以同篇文章、同一候选主体及其全部子事件为一组。共享一个可训练骨干，产生：

- 文章范围的 108 个原始分数 `p_A[k]`。
- 每个给定子事件的 108 个分数 `p_e[k]`。

`k=(价值,方向)`，使用 108 个独立 sigmoid，允许双方向、多个子事件和空标签。每个子事件必须仍有自己的表示，不能把文章表示复制成所有子事件预测。第一轮不同时加上下文门控、检索、合成数据和稀有标签过采样。

第一轮采用 ModernBERT-base 双向编码器：共同输入包含目标主体、正文和完整编号子事件列表，以固定分隔符界定各 scope 的 token 范围。正文范围和各子事件范围分别对有效 token 的隐藏状态做均值池化，接共享的 108 维预测头；输入不包含 gold 标签或解释。范围表示均可通过双向注意力读取完整输入，输入覆盖及 pool 范围需逐样本验证。T/J/S 使用完全相同的串行化、参数、池化规则、子事件顺序和长度预算。这是待实现的初始设计，不是已验证有效的表示方案。

后续 Llama 条件可在相同正文、主体和子事件信息之后，放置 article 及各 subevent 的无答案查询位置，以查询终止位置的隐藏表示接 108 维预测头；查询之间不填预测或 gold 标签。它与编码器实现的差异要记录，但 J/S 在每种骨干内部必须一致。分别比较各骨干上的 `S−J`，不能把 ModernBERT 的 J 与 Llama 的 S 之差归因于一致性方法。

以上都不是对组织方生成式 LoRA 基线的精确复现。若改用分别编码各 scope 的实现，也必须固定所有对照的输入和每组子事件覆盖，并明确计算成本。

### 6.2 只向上约束，不向下强行传播

对同一主体、同一个有向价值：

\[
\widetilde p_A=\max(p_A,p_1,\ldots,p_m).
\]

子事件预测 `p_e` 保持自己的分数。这个约束不会因为文章头漏报，就硬删子事件的正确预测。对 Task 2 的潜在收益来自训练，而不是把文章金标当推理候选过滤器。

借鉴 C-HMCNN 的 gold-aware max constraint loss，令文章标注为 `Y_A`，子事件标注为 `y_e`：

\[
q_A^+=\max\{p_A,y_1p_1,\ldots,y_mp_m\},
\]
\[
L_A^{scope}=-Y_A\log q_A^+-(1-Y_A)\log(1-\widetilde p_A).
\]

总损失为普通子事件多标签 BCE 加 `λ` 倍的上述文章损失，按 108 个标签及有效子事件数规范化。文章损失每个 actor bag 计算一次；不能因为一篇新闻子事件多，就反复计入同一个文章 gold。各方法采用同样的 article/actor group 权重。实现使用数值稳定形式，并显式检查有限值。

这里的 gold mask 只参与 TRAIN 损失，不参与推理。在所有子事件都是 0、文章是 1 时，`q_A^+=p_A`，文章正例只训练文章分支，不会为了满足文章标签去制造子事件标签。在文章是 0 时，高分子事件会得到额外纠正。文章与真实子事件同时是 1 时，能够利用两种粒度的支持。

**不能省略 gold mask 而直接对 `max(p_A,p_e)` 做普通正例 BCE。** 那样一个错误的子事件高分可能代替真正文章证据满足父标签，反而鼓励范围误归属。上述损失是已有方法的任务化使用，不宣称原创公式。

### 6.3 成立的研究假设与贡献边界

假设：在相同模型、上下文、article/subevent 标注和训练预算下，上述单向约束比独立联合训练更能减少缺乏文章级支持的子事件误报，同时保留召回，从而改善 Task-2b。

它可能失败：额外信息已被普通联合微调学会；梯度主要追逐少数最大误报；标注结构只在重复新闻中容易拟合；或作用相当于普通难负例加权。我们应主动比较这些解释。

成熟层级损失并不是新发明。“在 FEHU 使用 C-HMCNN”本身是否足以形成论文贡献，目前不能确认。较扎实的研究贡献应包括：明确范围关系和文章独有标签的处理、条件匹配的强基线、正文分组下的稳定收益，以及能够解释方法何时有效/失效的诊断。若只有通用方法迁移的小幅收益，应如实定位为实证结果。

## 7. 验证这个 idea 是否值得继续的实验

### 7.1 已经生成的固定划分

内部实验只使用官方 TRAIN。按相同标准化正文或相同标准化标题的连通分量分组，再用固定哈希顺序划分约 80/10/10。划分文件已写入 [grouped_train_split.json](evidence/grouped_train_split.json)，种子字符串为 `fehu-task2-scope-20261103`。

| 部分 | 新闻组 | GUID 记录 | actor bags | 子事件—主体组合 | Task-2b 正标签 |
| --- | ---: | ---: | ---: | ---: | ---: |
| fit | 678 | 973 | 2,650 | 23,783 | 14,624 |
| tune | 85 | 138 | 398 | 3,843 | 2,312 |
| holdout | 85 | 117 | 333 | 2,917 | 1,729 |

三部分的标准化正文和标题没有交集。**这还不保证语义近重复全部消失**；开始正式实验前，在不看标签和模型分数的前提下检查高相似文本对，若需合并，统一重新生成 manifest 并冻结，不能按效果挑选划分。当前全部 TRAIN 标签参与过汇总结构审计，内部 holdout 尚未用于模型、阈值或超参数选择。

第一轮中，fit gold 供训练；tune 供选阈值、checkpoint 和预先限定的超参数；holdout 在配置冻结后使用。官方 DEV 继续作为外部开发集，单独报告全文匹配 TRAIN 的 86 条与不匹配的 91 条。后者也不能自动称为完全无近重复测试集。

### 7.2 必要实验矩阵

本节用 T/J/S 等标识新实验，与刘原稿的 B0/B1 区分。

| 编号 | 条件 | 作用与可排除的混杂 |
| --- | --- | --- |
| T | 只训练子事件 BCE；保留相同模型和输入 | 测量新增文章监督的收益 |
| J | 子事件 BCE + 独立文章 BCE | **主要对照**。使用与 S 相同的两层监督 |
| P | J 的已缓存分数在推理后做 `p_article × p_subevent`，阈值只在 tune 决定 | 无额外训练；判断收益是否只是后处理。单独报告召回损失 |
| S | 子事件 BCE + 第 6 节的单向范围损失 | **待检验方法**；与 J 仅文章损失不同 |
| H | J + 普通组内难负例训练 | 检查 S 是否仅相当于增加最大误报的权重 |
| E | J + 训练专用解释目标 | EAVIT/DHRD 启发的强监督对照，测试另一个成熟路线 |
| E-shuffle | E 的解释在相同有向标签内跨新闻组置换，标签保持不变 | 若 E 有收益，检验实例解释是否比额外文本更有用 |

H 的具体初始规则：每个文章—主体—有向价值中，选择该标签 gold 为 0 的最高分子事件，增加 BCE 负项；候选只来自 fit，不能采用预测分数最高的 holdout 作为训练材料。比较时匹配额外项数量、归一化和权重搜索预算。它用的是发布集合中的非正标签，不称为人工验证的语义负例。

P 的上行 max 修正只改变文章头，不会改变 Task 2 分数，应作为实现一致性检查；用于 Task 2 的 P 固定为下行概率乘积，并要承担文章误报/漏报风险。若另外做 hard filter，应单列为诊断，不在 holdout 上挑选二者中的最好结果。

E 使用 fit 的正例解释作为训练目标。在 ModernBERT 条件中，解释只能送入单独的训练专用因果解码器作为目标，编码器和分类头始终只读原始输入；不能把解释拼入双向编码器再声称分类头没有看到答案。在 Llama 条件中，分类表示必须位于解释和 gold label token 之前，并保持 causal attention。E-shuffle 对无同标签、不同新闻组配对的稀有项，在 E 与 E-shuffle 都屏蔽该辅助项；普通标签监督保持不变。两组匹配解释覆盖和 token 数，单独报告辅助头参数及新增成本。它是思想适配，不是完整 EAVIT 系统复现，第一轮 J/S 不实现该辅助目标。

### 7.3 第一轮最小实验，先决定是否投入

第一轮只训练 **J 与 S**，同一模型、同一种子；P 直接复用 J 分数。这样先回答“约束是否比已经拥有文章监督的强对照更有用”，而不是用弱基线制造提升。

**骨干不绑定 Llama，当前优先 ModernBERT-base。** Task 2 是主体条件多标签分类；第 6 节损失只要求文章和子事件的标签概率，不依赖生成式模型。当前选择来自完整输入、分类表示和工程成本的匹配，不是已知 F1 排名，也不能用“参数更多”推断微调更好。

| 候选 | 当前用途 | 选择依据与限制 |
| --- | --- | --- |
| `answerdotai/ModernBERT-base` | 首轮 J/S 主骨干 | 双向编码器，约 149M 参数，原生 8,192 tokens，适合保留全文和子事件；没有 FEHU Task 2 的已验证优势 |
| `microsoft/deberta-v3-base` | 子事件分类强对照；后续可扩展为 J/S | 官方报告 86M 骨干加 98M 嵌入参数，标准配置 512 tokens；处理全文需统一分块和聚合，不能只截正文前 512 tokens 就声称看过全文 |
| `meta-llama/Llama-3.2-3B-Instruct` | 后续跨骨干 J/S 验证 | 长输入方便，与组织方 Llama 路线衔接；其 3B 微调并未被证明优于上述编码器 |

依据：[ModernBERT 模型卡](https://huggingface.co/answerdotai/ModernBERT-base)、[论文](https://arxiv.org/html/2412.13663)、[DeBERTa 模型卡](https://huggingface.co/microsoft/deberta-v3-base)及[配置](https://huggingface.co/microsoft/deberta-v3-base/blob/main/config.json)、[Llama 3B 模型卡](https://huggingface.co/meta-llama/Llama-3.2-3B-Instruct)。模型选择判断的信心为中等偏低；更长上下文和更低成本都不能代替本任务效果验证。

[Schwartz 价值识别相关研究，arXiv v4](https://arxiv.org/html/2605.22641v4) §7 表明经过监督训练的 DeBERTa 是有竞争力的方案，但其 LLM 对照采用零样本，标签也折叠为无方向的 19 类。不能据此得出 DeBERTa 优于微调 Llama、ModernBERT 最优或直接预测 FEHU 分数的结论。

项目已有 [train_deberta.py](../../src/train_deberta.py) 可参考标签映射和分类头，但它服务 Task 1、截断到 512 tokens，训练时只枚举文章 gold 中出现的主体。Task 2 必须重新构建完整子事件—候选主体集合并保留空标签；已有权重也不能直接用于分组 holdout。较小编码器无需强制使用 LoRA，是否全参数微调与模型类型是不同选择。

ModernBERT **建议启动配置，尚未实测**：全参数微调，编码器学习率 `2e-5`、新预测头 `1e-4`，AdamW，weight decay `0.01`，线性 warmup 10% 后线性衰减，3 epochs，`λ=1`，有效 batch 16 个 article–actor bags，种子 11。先用 BF16、micro-batch 1、梯度累积 16、梯度检查点和受支持的高效注意力。模型 revision、tokenizer、软件版本和 J/S 初始权重固定。峰值显存与长度覆盖通过后才开始正式训练。

后续 Llama 3B 的候选配置另行保留：LoRA `r=16, alpha=32, dropout=0.05`，q/k/v/o，LoRA 学习率 `2e-4`、新预测头 `1e-3`；共享划分、可见信息、阈值协议和 J/S 配对设计。不能把 Llama 的学习率原样移给 ModernBERT 全参数微调。跨骨干不要求不同 tokenizer 的 token 序列完全相同，但必须报告信息覆盖、实际 token 数和预算。

文本预算先定 8,192 tokens，包括主体、正文、全部子事件及分隔符。先对**实际 tokenizer**审计长度；超过预算时停止并制定统一分块及聚合方案，不能静默截掉部分子事件继续跑，也不能直接把 ModernBERT 配置长度改大就假定有效。J/S 共享最终输入缓存。因资源问题调整输入预算或 batch 时，两个条件同步调整并重跑，不能只给其中一个方法更多可见文本。

3 epochs 是启动预算，不代表已经收敛。先确认 J 能学到非平凡预测，并检查 train/tune 曲线；若仍明显欠训练，则按预先约定把 J/S 同步延长到 6 epochs。不能把未训练好的分类头或全空塌缩当成方法无效的证据。反之，也不能只延长 S 到最佳点而保留较差的 J。

若 6 epochs 后仍明显欠训练，本轮只能报告预算内证据不足，不能直接判定方法失败。下一轮的收敛预算需在查看 holdout 前统一制定。DeBERTa 单任务结果用于建立任务基线，不代替相同骨干和输入的 J/S 比较。

所有 108 个位置参与监督，不下采样空 actor，不增加“每主体至少一项”规则。先采用一个全局阈值：在 tune 的 `0.05–0.95`、步长 `0.01` 网格上最大化 Task-2b Micro-F1，每个条件用相同搜索预算，分数相同取较高阈值。另报告阈值无关的 micro-AP、P/R 曲线，避免把校准变化误称为更好的表示。

完成第一个种子的 tune 评估后：若 S 比 J 提升至少 **1 个 F1 百分点**，或在 J 的召回水平附近能减少至少 **10% 误报**，进入重复实验。这里是**事先建议的继续门槛，不是预期结果**。若指标分歧，查 TP/FP 和错误类型；不凭单次最高值宣布成功。

若 S 没有增益，先检查范围损失是否真正作用到子事件、是否错误归一化以及空标签实例是否完整，然后在相同调参预算下检查 `λ∈{0.25,1}`。通过实现检查仍无改善，就停止扩大该方法，不增加多个组件救分。可转而测试 E，但要明确研究问题已经改变。

### 7.4 完整验证的“好结果”标准

通过初筛后固定方法与配置，用种子 **11、23、47** 完成 ModernBERT 的 T/J/S/H；E 与 E-shuffle 作为解释路线对照。随后在 Llama 3B 上成对验证 J/S，不能只靠一种骨干声称通用有效。资源允许时再用与组织方一致的 Llama-3.1-8B-Instruct 扩展验证；8B 不是第一轮必需条件。各骨干内固定相同输入，原论文 TEST 成绩不能直接作为消融行。

在内部 holdout 上，建议把以下证据共同作为“值得形成主要研究结果”的门槛：

1. S 相对 J 平均 Task-2b Micro-F1 提高至少 **2 个百分点**，三个种子的差值都为正。
2. 以新闻组为单位做 2,000 次配对 bootstrap，平均 F1 差值的 95% 区间下界大于 0。每次各方法使用相同组样本，并保留重复抽样的权重。报告种子间范围；该区间不覆盖全部训练随机性。
3. Macro-F1 不下降超过 1 个百分点；召回不下降超过 1 个百分点，并检查相同召回下的 precision。DRR 与正标签覆盖一起读。
4. 收益超过 P，并在 H、E 面前仍有可说明的优势或互补性。若 H 同样有效，应把结论改为难负例加权，不能宣称范围结构独有贡献。
5. 官方完整 DEV 与非正文重叠子集分别报告，收益不应只来自重叠记录。只在重叠子集成立，不能支撑新新闻泛化。

这些是项目决策阈值，不是统计功效计算的结果。85 个 holdout 新闻组可能产生较宽区间。效果方向好但区间跨 0，应记为**证据不足**，保留配置后追加预先固定的分组重复验证或新的独立标注数据，不能把不显著等同于无效，也不能不断重抽 split 挑结果。

### 7.5 必须报告的诊断，防止“一致但一起错”

主表使用官方 Task-2b Micro/Macro-F1、P/R、DRR，以及映射后的 Task-2a。另保存连续分数，报告 micro-AP。以下诊断与主指标分开：

- **文章不存在型误报**：子事件预测为正，但同主体文章 gold 不含该有向标签。只在评测时按 gold 分类，不进入推理。
- **文章存在、事件不成立型误报**：文章有标签，但当前子事件没有。它是范围错误候选，语义原因仍需人工查阅。
- **文章独有标签下传率**：4,117 类 TRAIN 结构对应的评测样本中，是否把只在文章出现的标签错误传到任一子事件；报告分母。
- **原始分数违反率**：在最终 max 修正之前，统计 `p_e>p_A`；最终结构保证的一致率不能作为独立成绩。
- 按 TRAIN 频次、方向、子事件数、正文重复状态分层，列出每层样本数。选取新增 TP、减少 FP、损失 TP 的真实案例，隐藏方法名后审查。

若所有预测都为空，一致率可能完美，F1 却不可用。若文章头错误被向上抬高，结构也会一致。因此一致率只解释机制，不能代替识别性能。

可加一个 **oracle article filter**：把 J 子事件预测中不属于 gold article 的标签删除。当前包含关系下，它不会删除 gold TP，可量化“仅过滤文章不存在型误报”的诊断潜力。必须标为不可部署的 oracle，它只给这种固定预测后处理的上限，不是整个 S 方法的理论上限。若 oracle 提升不到 0.5 点，说明这类错误空间小，应降低对一致性方法的期待。

fit 有 2,650 个 article–actor bags。按建议有效 batch 16，每 epoch 约 166 个 optimizer steps，3 epochs 约 498 步/条件；两个条件、单种子约 996 步。若每 bag 单独 forward、梯度累积 16，则约 7,950 个训练 forward/条件，验证另计。最终以实际长度分桶、packing 和梯度累积日志为准，不把 optimizer step 与 forward 次数混淆。

### 8.1 RTX 4090 与训练时间

建议使用现有的普通 RTX 4090 24GB 电脑做本地试验。[NVIDIA 规格](https://nvidianews.nvidia.com/news/nvidia-delivers-quantum-leap-in-performance-introduces-new-era-of-neural-rendering-with-geforce-rtx-40-series)只证明硬件容量，不是本任务显存或速度测试。优先使用已可运行 CUDA/PyTorch 的 Linux 环境；尚未连接该电脑，不能假定其系统、空闲显存和依赖已满足。ModernBERT 全参数微调的 8K 输入可行性要先用最长样本验证；Llama 3B 的 LoRA 也需独立测量。必要时评估量化适配，但 J/S 必须采用同一种配置，量化不能被写成一定更快。

先检查输入长度分布，并对长样本做峰值显存测试；预热后按训练长度分布取至少 50 个 micro-batches 计时，同时记录一次完整 optimizer step。排除编译/下载初始化耗时，明确梯度累积次数。`micro-batch`、完整样本和 optimizer step 不是同一计数单位。两个条件都测量，以 `T_train = 样本数 × epochs × 实测平均秒/样本` 估算，再加实际验证和保存成本。

下表仅是**此前 Llama 规划的条件算例，绝非 4090 实测，也不是 ModernBERT 速度预测**。假定每 bag 一次训练 forward/backward、micro-batch 1，平均每 bag 用时 2–4 秒，且 J/S 相同：

| 范围 | 两个条件的样本处理次数 | 纯训练时间 |
| --- | ---: | ---: |
| J/S 各 1 epoch | 5,300 | 2.94–5.89 小时 |
| J/S 各 3 epochs | 15,900 | 8.83–17.67 小时 |

在上述假设成立时，可给 3-epoch 比较暂留约一天机器时间；每样本更慢、验证更重或需要分块都会延长。ModernBERT 改用实测值重算，不继承这一天预算。环境安装、模型下载、训练器实现及调试均不包含在表中，目前不能承诺从现在起几小时内产出结果。1 epoch 只能观察学习是否启动和大致趋势；方法是否有效仍按第 7 节判断。

### 8.2 AI 模型、API 与成本边界

第一轮需要 AI 模型，但**不需要付费 AI 推理 API**。流程是下载预训练权重，在本地训练 J/S，在本地导出预测，再用项目评价器评分。使用已有官方 TRAIN 标注，不新增大模型生成标注。Hugging Face 下载认证或模型许可证接受与按 token 计费的推理 API 是不同事项；Llama 的具体下载要求以模型页为准，凭据只保存在本机环境中。

在已有电脑上，主要增量成本是机器占用和电力，不是 API token。实际电费必须按整机实测功耗、运行时间和电价计算，不能用 GPU 标称功率直接当整机费用。云端教师、解释生成或闭源模型比较属于后续独立实验，若采用应另列费用和对照，不是本次 J/S 的依赖。

当前没有为训练申请 GPU、调用付费模型或生成训练成绩。已有 Task 1 权重可能看过整个 TRAIN，不能直接拿来做上述 holdout 的“未见新闻”模型；应从固定基础 checkpoint 训练，或在 fit 内重新训练。

## 9. 可以直接用于决策的结果解释

| 观察到的结果 | 可支持的结论 | 决策 |
| --- | --- | --- |
| S 稳定优于 J/P/H，并在分组 holdout 和第二种骨干上成立 | 范围结构比普通联合监督、后处理和难负例训练更有用 | 继续深化并研究与刘上下文策略的交互 |
| S 优于 T，但不优于 J | 主要是多粒度监督收益 | 使用 J，不宣称结构方法有效 |
| S 与 H 相当 | 可能主要是难负例加权 | 简化方法，重新界定贡献 |
| S 只改善一致率，F1 不升或召回明显下降 | 结构正确不等于标签正确 | 停止把一致率当目标成绩 |
| E 优于 S 且优于 E-shuffle | 实例解释监督更值得投入 | 将新研究主线转到解释信息的有效性 |
| E 与 E-shuffle 相当 | 额外语言监督/正则化可能解释收益 | 不声称模型学会了正确解释 |
| 收益只在正文重叠 DEV 出现 | 尚无新新闻泛化证据 | 不以完整 DEV 的单一高分作为成功依据 |

**当前结论：优先投入一个小规模的 J/S/P 实验。这个 idea 的吸引力是关系能被真实数据支持、实现有成熟依据、关键对照明确；它的效果和论文新颖性都尚未被证明。**

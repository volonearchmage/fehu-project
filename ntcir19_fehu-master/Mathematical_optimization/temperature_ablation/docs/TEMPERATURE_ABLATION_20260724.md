**基线：** E1 Prompt (baseline), DeepSeek V4 Pro (non-thinking), 177 dev articles
**控制变量：** 仅改变 `temperature`，Prompt/shot/model 完全不变

## 三、关键发现

### 3.1 T=0.0 全面碾压 🔥

**T=0.0 在所有 8 个核心指标上均优于或等于 T=0.1 和 T=0.3：**

| 相对 T=0.1 的提升 | Δ |
|---|---|
| 1b Micro F1 | **+0.0101** |
| 1b Macro F1 | +0.0060 |
| 1b Precision | **+0.0195** |
| 1a Micro F1 | +0.0064 |
| 1a Macro F1 | **+0.0139** |
| DRR | **−0.0040** (少 9 次翻转) |

### 3.2 温度效应出乎意料

直觉预测：温度越高 → 更多预测 → 更高 Recall、更低 Precision。但实际观测：

```
T=0.0: 2686 预测,  Precision 0.5101,  Recall 0.5732
T=0.1: 2805 预测,  Precision 0.4906,  Recall 0.5757
T=0.3: 2681 预测,  Precision 0.5006,  Recall 0.5615
```

**T=0.1 预测最多但 Precision 最低**——这不是单调的温度效应。可能的解释：
- T=0.1 引入的微小随机性让 LLM 在决策边界上"犹豫"，导致更多边界标签被输出但质量较差
- T=0.0 的确定性输出更一致、更精准
- T=0.3 反而可能因为高随机性让 LLM 在某些文章上更保守

### 3.3 与已有系统的对比（T=0.0）

**T=0.0 已将 Pro 的 1b Micro 从 0.5297 推至 0.5398**，超越刘 frozen (0.535)，但仍低于刘 Ensemble (0.5543)。DRR 仍是主要短板。

## 四、温度间交集分析（初步）

### 4.1 预测重叠矩阵

| 预测重叠 | 含义 |
|---|---|
| T=0.0 ∩ T=0.1 ∩ T=0.3 | 三温一致的预测 → 高置信度核心集 |
| T=0.0 only | T=0.0 独有 → 需验证 Precision |
| T=0.3 only | T=0.3 独有 → 潜在 Recall 补充 |

> 详细逐标签交集分析待后续离线完成。

### 4.2 集成假设

如果三温预测有明显互补性：
- **高置信核心** = 三温交集 → Precision 极高
- **召回补充** = T=0.3 独有（经方向验证）→ Recall 提升
- **最终预测** = 核心 ∪ 补充 → 同时提升 Precision 和 Recall

---

## 五、结论

1. **T=0.0 是 Pro 的最优单温度**：8/8 指标领先，应作为后续所有实验的默认温度
2. **Pro 不需要高温来提升 Recall**：T=0.3 的 Recall 反而最低（0.5615）
3. **温度对 Pro 的影响非线性**：T=0.1 是最差的中间点
4. **DRR 仍需解决**：最优 T=0.0 的 DRR (0.0518) 仍是刘 frozen (0.023) 的 2.25 倍

---

## 六、下一步

1. **完成三温交集分析**：计算独有预测的 Precision/Recall 贡献
2. **T=0.0 + Flash 方向验证**：用 Flash 的高方向精度修复 Pro 的 DRR
3. **T=0.0 + A3 修复版**：修复 actor 名称传递后，在 T=0.0 基础上叠加贝叶斯先验
4. **无需做 TAME**：三温集成在 Pro 上无意义——T=0.0 单独就是最优，T=0.1/0.3 只会拉低质量

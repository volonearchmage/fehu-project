## 二、A3: 贝叶斯 Actor-Type 先验

### 2.1 方法

$$P(y_c=1 | x, t) \propto P(y_c=1 | x) \cdot \frac{P(y_c=1 | t)}{P(y_c=1)}$$

- 从训练集估计 $P(c|t)$（14 种 actor 类型的条件概率）和 $P(c)$（全局先验）
- Bayes Factor $BF = P(c|t) / P(c)$，当 $BF > \alpha_{add}=2.0$ 时添加标签
- 仅做加法（additive），不删除 E1 原有预测

### 2.2 结果

```
[A3] Bayesian Prior: added 0 label instances across 177 articles
```

**添加 0 个标签。** 原因：E1 预测 JSON 中不含 actor 名称（仅有 actor_id），`classify_actor_type()` 对所有 actor 返回 `"Unknown"`。在 Unknown 类型下，$P(c|Unknown) \approx P(c)$ → $BF \approx 1 < 2.0$ → 无任何标签被添加。

### 2.3 修复方案

需要将 actor 名称传入 A3 流程：
1. 同时读取 `dev_event_base.json` 的 actor 信息
2. 或在 E1 输出中增加 `actor_name` 字段
3. 或用 actor_id 的 hash 模式匹配训练集中的 actor 类型

## 三、A4: 标签共现图正则化

### 3.1 方法

- 从训练集构建 108×108 标签共现矩阵 $W_{ij} = P(y_j=1 | y_i=1)$
- 图扩散：$p^{(t+1)} = (1-\alpha) p^{(0)} + \alpha \cdot S \cdot p^{(t)}$（$S$ 为行归一化邻接矩阵）
- 参数：$\alpha=0.3, T=3, \tau=0.5$

### 3.2 结果

```
[A4] Graph Diffusion: added 0 label instances across 177 articles
```

**添加 0 个标签。** 共现矩阵稀疏度 46.8%，但扩散强度不足：
- $\alpha=0.3$ 表示 70% 信任原始预测，仅 30% 信任图信号
- 图扩散 3 步后，任何新标签的得分均未超过 $\tau=0.5$
- E1 原始预测的标签保持在 1.0，未被扩散的新标签最高约 0.2-0.3

### 3.3 参数扫描建议

| 参数 | 当前值 | 建议尝试 | 预期效果 |
|---|---|---|---|
| $\alpha$ | 0.3 | 0.5, 0.7 | 更强图信号 |
| $T$ | 3 | 5, 7 | 更远传播 |
| $\tau$ | 0.5 | 0.3, 0.2 | 更低接受门槛 |

### 3.4 数值稳定性

使用行归一化（random walk Laplacian）替代对称归一化后，数值稳定性改善。仍有 BLAS 级 matmul 警告，但计算结果的 NaN 已被 `np.nan_to_num` 处理，不影响输出。

## 四、A5: 混淆矩阵谱分解纠偏

### 4.1 方法

- 在 dev 集上构建 108×108 混淆矩阵 $C_{ij} = P(\text{predict } j | \text{gold } i)$
- SVD 分解：$C = U\Sigma V^T$，取前 $r=5$ 个奇异向量
- 纠偏：$p' = p - \eta \cdot U_r U_r^T p$（$\eta=0.3$）
- 仅做减法（subtractive），压制 $\text{score} < 0.3$ 的标签

### 4.2 混淆模式

| 模式 | 主标签 | 解释 |
|---|---|---|
| Mode 1 | (1,17), (1,24), (1,49) | 正向价值间的混淆 |
| Mode 2 | (1,17), (0,31), (0,46) | 正向价值与安全/国家类的反向混淆 |
| Mode 3 | (0,3), (0,7), (0,8) | 反向价值间的混淆 |

Top 5 奇异值解释 68.6% 的混淆方差。

### 4.3 结果

```
[A5] Spectral Debiasing: dropped 3 label instances across 177 articles
1b Macro F1: 0.3854 → 0.3836 (−0.0018)
```

**仅压制 3 个标签，Macro 微降。** 原因：
- $\eta=0.3$ 太保守——投影量不足以将置信标签压到阈值以下
- E1 的输出是离散的（0/1），而非连续概率——谱纠偏对 one-hot 向量的效果有限
- 需要更大的 $\eta$（0.5-0.8）才能产生显著效果

### 4.4 参数扫描建议

| 参数 | 当前值 | 建议尝试 |
|---|---|---|
| $\eta$ | 0.3 | 0.5, 0.7, 0.9 |
| $r$ | 5 | 3, 8, 10 |
| suppress_threshold | 0.3 | 0.5, 0.7 |

> ⚠️ 当前混淆矩阵在 dev 上估计（诊断用）。正式提交前需在 sub_train 上重新估计。

## 五、综合诊断

### 5.1 为什么三个方法都接近零效果？

| 方法 | 根本原因 | 性质 |
|---|---|---|
| A3 | Actor 名称缺失，无法做类型匹配 | 数据管道问题 |
| A4 | 参数太保守（α=0.3, τ=0.5） | 参数选择问题 |
| A5 | η 太保守 + one-hot 向量对连续纠偏不敏感 | 参数+方法问题 |

### 5.2 核心洞察

1. **A3 需要修复数据管道**：将 actor 名称传入后处理流程（低难度修复）
2. **A4 的共现结构本身可能不够强**：46.8% 稀疏度暗示许多标签对之间无显著共现关系——标签独立性假设可能大致成立
3. **A5 对 one-hot 预测效果有限**：谱纠偏假设输入是连续概率向量，对离散 0/1 预测的调整空间不足

### 5.3 与优化方案预期的对比

| 方法 | 预期增益 (1b micro) | 实际增益 | 状态 |
|---|---|---|---|
| A3 | +0.003–0.008 | 0 | ⚠️ 需修复 |
| A4 | +0.002–0.005 | 0 | ⚠️ 需调参 |
| A5 | +0.001–0.004 | −0.0018 | ⚠️ 需调参/重构 |
